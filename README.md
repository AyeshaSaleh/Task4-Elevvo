# 📊 Task 4: Superstore Sales Dashboard (Power BI)

This project was developed during my internship at **Elevvo Pathways**. It features an interactive, multi-page Power BI dashboard designed to provide a 360-degree view of retail operations, sales performance, and profitability using the Superstore dataset.

---

## 🎯 Project Objective
The goal was to create a business intelligence solution that allows stakeholders to track Year-over-Year (YOY) growth and identify underperforming regions or categories through data-driven storytelling.

## 🛠️ Technical Skills Applied
* **Power BI Desktop:** Full report development from data ingestion to visualization.
* **DAX (Data Analysis Expressions):** Created custom measures for YOY Growth, Profit Margin %, and Total Revenue to provide deeper analytical layers.
* **Data Modeling:** Established relationships between tables to ensure accurate cross-filtering and drill-down capabilities.
* **UI/UX for BI:** Designed an intuitive layout with consistent color schemes and navigation for better user experience.

---

## 🚀 Key Features & Insights
* **YOY Growth Trends:** Dynamic time-series analysis comparing current performance with previous years.
* **Performance Breakdown:** Granular views of Sales and Profit by Category and Sub-category.
* **Regional Intelligence:** Map-based visualizations highlighting geographic sales distribution and shipping efficiency.
* **Ship Mode Analysis:** Comparison of profitability across different shipping methods to identify cost-saving opportunities.
* **Interactive Slicers:** Advanced filtering by Year, Region, and Segment for customized reporting.
